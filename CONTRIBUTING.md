# Contributing

Use Node 24 and `npm ci`. Copy `.env.example` to `.env.local`; never commit keys. Create a branch, make focused changes, and run the checks listed in AGENTS.md. Add meaningful tests for grading, transitions, provider failures, and user journeys. Curated educational content needs subject review; translations need fluent speaker review. Keep retrieved material separate from generated explanations and learner records.

Dependency license information is recorded in docs/THIRD_PARTY.md. The application source is MIT; third-party packages retain their own licenses.
