# User flows

1. Landing → Learn: choose a curated topic or type a topic, select language and starting level, record a goal/time preference.
2. Classroom: request an explanation; mode and latency are shown. Change strategy, language, or submit a follow-up. Research is opt-in and errors clearly without keys.
3. Diagnostic: answer two MCQs; score and tentative gaps are recorded. Incorrect answers link to a simpler explanation.
4. Lab: vary transformer turns/supply, trace the fixed Python program, or vary quadratic coefficients.
5. Practice: use a different question set; correct responses suggest new applications; weak responses suggest review/retry.
6. Progress: compare the first diagnostic and latest practice, inspect history, choose revisions.
7. Settings: save preferences, inspect configuration, export records, or clear browser data.
8. Roadmap: generate and edit a curated schedule; check off activities. Checkmarks are self-reported and not automatically treated as mastery.
