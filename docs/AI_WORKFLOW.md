# AI and adaptive workflow

REA update: course requests include prerequisite and weak-concept context. Strategies change steps → simple → worked across bounded reteaching; an explicit simpler request is respected. Test instructions ask for reasoning and a guiding hint before revealing answers. Live-model compliance is NOT TESTED. Concept reviews derive from recorded attempts, ignore invalid/future/duplicate evidence, and increase suggested 1/3/7/14-day stages only after successful checks at least 24 hours apart. Recall/self-check guides assign no grades or completion. No migration or additional inference is needed; see REA.md.

Course orchestrator: ASSESS → DIAGNOSE → PLAN → TEACH → PRACTICE → EVALUATE → ADAPT → COMPLETE, another TEACH, or REVIEW. Validated edges/state replay reject altered scores/gaps and invalid attempt order. Two reteaching rounds; third failed practice pauses at REVIEW with progress intact. COMPLETE means passing these checks.

One outline call covers 3–30 ordered days. Lesson actions load one diagnostic, one teaching response, one post-quiz and up to two reteaching responses, each allowing one transient retry. Reused practice questions cannot establish independent gains. Demo outlines/quizzes require no inference. On-demand lessons retain fixture/live mode and validated language/preferences.

PDF retrieval matches Unicode words/combining marks, at most three 1200-character passages with genuine IDs/pages. UI requires consent; fixtures reject document grounding. Prompts treat passages as untrusted; injection resistance and factual grounding cannot be guaranteed. LangSmith excludes document contents.

Validated transitions: INITIAL → DIAGNOSTIC → ANALYSIS → LESSON → PRACTICE → EVALUATION → MASTERED or RETEACH. Optional diagnostics allow INITIAL → LESSON; RETEACH → LESSON; MASTERED → PRACTICE. `MASTERED` is an internal state for correct concept checks, not a claim of subject mastery.

Assessment scoring is deterministic. A wrong response records a concept and a tentative classification, because MCQ mistakes do not prove a particular psychological cause. Review explanations teach the rationale. The classroom switches to simpler instructions when a reteach link is used. Each strategy has distinct model instructions; language and level are included. One logical tutor can serve all teaching roles without expensive multi-agent hosting.

Live provider output must match the Lesson schema. Invalid JSON/shape fails visibly. Source URLs originate only in Tavily responses and are HTTPS-validated and deduplicated. Relevance accepts a score of at least 0.5, or at least 0.35 with two meaningful query terms and sufficient topic overlap. This is a relevance heuristic, not a truth or authority check. Sources are listed as retrieved context rather than fabricated citations. Retrieved text and user input are explicitly designated untrusted in model instructions.

LangSmith wraps lesson and structured-task generation with redacted input/output processing. Lesson traces retain only provider, latency, and token counts when supplied by the provider; learner inputs and generated explanations are removed. Up to four previous explanation excerpts of 1000 characters each provide topic-specific conversation context. History is stored with topic, language, and strategy so unrelated lessons are not used as follow-up context. `/api/workflow` supports generated diagnostics, written-answer rubric evaluation, and generated roadmaps. Schemas check correct option indices, point bounds, matching rubric identifiers, and exact ordered roadmap days. The Assessment and Roadmap pages provide live-provider review interfaces. Fixture mode rejects these tasks explicitly; it never fabricates model reasoning. Mock-transport adapter tests do not verify hosted inference.

Phase 10 introduces nested LLM and retriever traces, standard usage_metadata with actual input/output/total tokens, model/provider metadata, aggregate written-rubric scores and tentative-gap counts, and a shared SDK client flushed after serverless route completion. Raw questions, answers, explanations, guest tokens and organizer codes are never intentionally logged. The trace smoke confirms remote visibility and redaction with a fixed synthetic sentinel when credentials exist; it is currently BLOCKED. Model-generated rubric scores are suggestions, not measured educational improvement. Fixture lessons reject research to avoid spending Tavily credits without grounding a live explanation.

Research lesson validation additionally requires supplied [source:N] citations. Raw retrieved excerpts remain untrusted data. This check rejects fabricated citation IDs and missing grounding references; independent source/claim review remains necessary.
