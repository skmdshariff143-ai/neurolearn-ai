# Security review

2026-10-14 restricted preview: NEXT_PUBLIC_SAFE_PREVIEW is a build-time policy (rebuild to change it), forcing fixtures and disabling live routes/research/tracing/hosted data APIs and PDF extraction. Client storage uses temporary memory rather than localStorage; old records are not read/deleted. Preview smoke/catalog commands are blocked to prevent false inference evidence. All pages display explicit fixture/privacy limits and noindex metadata is set. These controls do not authenticate reviewers: Vercel protection, signed-out denial and authorized access must be verified on the real Preview URL. No hosted isolation is asserted; upload/private persistence remain disabled. Git ignores credentials, databases and named learner export/data directories; secret/PII review remains limited, not a proof for every possible format.

PDFs: 2 MiB/20 pages, 15-second parser teardown, 10,000 characters/page, 100,000 total. Same-origin PDF.js worker text extraction; this UI never executes embedded scripts/forms/files. Unsupported/encrypted/image-only files fail visibly. Browser profiles are shared-device boundaries, not accounts; avoid sensitive notes.

Hosted library uses bounded bodies, origin checks, organizer access, shared 30/minute quota, validated snapshots, forced RLS and composite owner FKs. Separate local/hosted deletion; guest deletion cascades. Account linking, conflict detection, retention operations, backups and hosted checks remain outstanding. Production dependency audit including PDF.js returned zero advisories; existing development limitations below remain.

API keys are server-only env vars. No NEXT_PUBLIC credential variables exist. React renders model explanations as text, preventing HTML execution. KaTeX receives a fixed developer-controlled formula. User code is never executed. Tutor requests validate topic/language/strategy and bound message size. Cross-origin requests are rejected, session cookies are HttpOnly/SameSite strict, and responses avoid caching learner text. Headers disable framing and MIME sniffing and restrict unnecessary browser capabilities.

External calls use timeouts and bounded retries. Live errors never fall back to fixtures. Local inference accepts only loopback hostnames. Production fixtures need explicit opt-in. Public status shows booleans/configuration only, no secrets.

Phase 10 adds a signed one-hour organizer-access cookie and PostgreSQL shared global/per-access budgets for production external calls. Missing configuration/backend fails closed. Hosted progress is consent-based and organizer-gated in production, with private guest cookie capabilities and forced PostgreSQL RLS; runtime roles with superuser, RLS-bypass or table ownership are rejected. The repository accepts answers for server grading, never client-supplied scores or learner IDs. Cross-site Fetch Metadata is rejected even for progress GETs. Request body reading is byte-bounded. CSP blocks off-origin browser scripts/fetches, frames and objects while retaining inline script/style compatibility needed by this build.

Known limitations: fixed-minute quotas do not eliminate denial of service; browser storage is readable within that browser profile; guest cookies have no account recovery; CSP is not nonce-based; retention maintenance and legal/child review are pending. RLS/repository tests pass on embedded PostgreSQL, but hosted networking, role grants, certificate trust and isolation remain unverified. No formal penetration test was performed.

Do not publicly onboard children until parental consent, age handling, retention, deletion, and applicable legal obligations have been reviewed. Generated safety instructions reduce risk but are not a guaranteed safety classifier.

Dependency audit on 2026-10-13: production dependency audit returned zero advisories. Full audit after upgrading LangSmith, KaTeX, and Vitest still reports five high advisories in development dependencies (braces → micromatch → fast-glob → Next.js ESLint tooling). Registry latest braces is 3.0.3 and the reported range includes it; a speculative 3.0.4 override failed because no such release exists. No forced incompatible ESLint/Next.js downgrade was applied. Do not feed untrusted glob patterns into development tooling. This remains a known development security limitation.
